# Image Annotation Visualizer 🎯

A sleek, premium, and local-first web application designed to inspect, navigate, and visualize image detection/annotation datasets effortlessly.

## ✨ Features

- **Multi-Format Support**: Seamlessly parses COCO datasets, flat JSON dictionaries, and structured annotation list formats.
- **Glassmorphism UI**: Built with a modern, high-fidelity dark-mode interface, featuring smooth micro-animations and Google Fonts typography.
- **Interactive Overlay**: Shows bounding boxes with dynamic color assignments per category, toggleable labels, and exact coordinates on hover.
- **Native File Explorer Integration**: Click-to-browse file and folder pickers using Tkinter dialogs to load datasets without typing paths manually.
- **Keyboard Shortcuts**: Swiftly navigate through your dataset using arrow keys (`←` / `→`) and toggle annotations with `L`.
- **Dynamic Category Count**: Shows category legends per-image for fast data distribution analysis.
